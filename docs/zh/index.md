# 简介

Kero 是一款面向编程智能体的终端，支持 macOS、Windows 和 Linux。Claude Code、Codex、开发服务器或测试监视器，各自运行在独立的**会话**中。Kero 在边栏中按项目归类会话，哪些在工作、哪些在等你、哪些已经完成，一目了然。

## 窗口关了，会话还在

会话并不运行在应用里，而是运行在 **kerod** 中——这是 Kero 替你启动的一个小型守护进程。退出 Kero，一切照常运行；再次打开，每个会话、窗格和回滚缓冲都停留在你离开时的样子。

::: tip
退出 Kero（<kbd>⌘</kbd> <kbd>Q</kbd>）不会结束会话。要全部结束，请使用 **Kero › 退出并结束所有会话…**（<kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>Q</kbd>）。
:::

## 为智能体而生

- **状态一目了然。** 每个窗格的状态为*工作中*、*等待中*、*空闲*、*出错*或*已退出*之一。需要你处理的会话会被优先提示，按 <kbd>⌘</kbd> <kbd>J</kbd> 即可直接跳过去。
- **该提醒时才提醒。** 当你在看别处时，智能体完成、失败或等你操作，Kero 都会通知你。
- **智能体可以驱动的命令行。** `kero` 命令可以启动会话、拆分窗格、向其中输入、等待它们并读取屏幕内容。智能体可以在自己旁边运行任务，并汇报自身进度。
- **底层是 Ghostty。** 终端由 libghostty 渲染，Ghostty 的主题、字体和配置项都会如你所料地生效。

---
title: Kero 是什么
description: 原生 macOS 终端工作区——项目、会话、浏览器、文件、git 与编码 agent，都在同一个窗口里。
---

Kero 是一个终端。窗口里其余的部分，是为了让你不必离开它。

你手上的每个仓库，都会成为侧边栏里的一个**项目**。一个项目可以开任意多个终端**会话**，每个会话是一个标签页，有自己的工作目录和滚动历史；每个标签页还可以**分屏**成多个窗格。在这一切旁边是侧边面板，各自只需一个快捷键：用来审阅和提交的 git 面板、带编辑器的文件树，以及当前会话正在跑哪些进程、开了哪些端口的实时视图。

浏览器窗格和编码 agent 状态也在同一个项目布局里，不会再变成一堆要单独管理的窗口。

终端窗格可以选择 [Ghostty 或 Alacritty](/zh/docs/terminal#终端后端)，两者都由 Kero 原生承载并用 GPU 渲染。你的 shell、提示符、别名和 dotfiles 一律原封不动。

![Kero 中打开了 git 面板的终端会话](/kero-screenshot.png)

## 它不是什么

Kero 不是 IDE，也不打算变成 IDE。git 和文件面板的存在，是为了让你不切换应用就能读一段
diff、改一个错字——而不是让你整天泡在里面。它也不会背着你做事：每一个 git 操作都对应一条你本可以自己敲的命令，输出会原样展示给你。

## 免费，而且很低调

Kero 免费且开源（GPLv3），不需要账号，也没有订阅。它不发送任何遥测数据，不做分析统计。它自己发起的唯一网络请求，是向 `releases.kero.sh` 检查更新；浏览器和 agent CLI 只会发起你明确要求的请求。

---

用 <kbd>Cmd</kbd>+<kbd>,</kbd> 打开设置。窗口里的一切都会直接写进一个纯文本 TOML 文件，
所以你也可以手动改它，或者把它放进自己的 dotfiles。

## Appearance

**Theme**——跟随 macOS，或强制 Light / Dark。那三个预览图是用真实配色画出来的迷你 Kero
窗口。

## Colors

两个选择器，每种外观各一个：一个**深色主题**和一个**浅色主题**。系统外观切换时，Kero 就
在两者之间切。

列表里是 Kero 自己的 Default，加上整个内置的 Ghostty 主题目录——共 485 个。换主题会同时
给终端、窗口装饰、侧边栏和编辑器重新上色，即时生效，不用重启。

<Callout type="info">
内置的 Default 保留 Kero 源自 GitHub 的配色和半透明侧边栏。其余每个主题也会一并给侧边栏
上色。
</Callout>

## Font

- **Family**——内置并默认使用 JetBrains Mono；任何已安装的等宽字体都可以替换它。
- **Size**——8 到 32 磅。
- **Thicken font strokes**——更粗的字形笔画，像经典的 macOS 字体平滑。默认关闭，这样文字
  和原版 Ghostty 一致。

下方的预览同时包含常规体、粗体和 Nerd Font 符号，方便你看清换字体之后提示符里的图标还在
不在。

终端、编辑器和 diff 视图用的是同一套字体。

## Terminal

**Restore session history on relaunch**——重开的终端会在 `Session Contents Restored` 分隔线
上方显示之前的滚动缓冲区，新 shell 在下方。默认关闭，因为打开意味着捕获到的终端输出会被
写到磁盘上。

## Text Editing

**Wrap lines to editor width**——默认关闭，长行改为横向滚动。

## Updates

**Automatically check for updates** 开关，以及一个 **Check for Updates…** 按钮。见
[安装](/zh/docs/installation#更新)。

## Reset to Defaults

把上面每一项设置都恢复原状。它不会动你的项目、会话或窗口布局。

## 配置文件

```
~/.config/kero/config.toml
```

设置一变，Kero 就写一次这个文件，而且只记录和默认值不同的项——一份没什么特别配置的文件
几乎是空的。

| 键 | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `theme` | `"system"` \| `"light"` \| `"dark"` | `"system"` | 外观覆盖 |
| `theme-dark` | string | Kero 的深色默认 | 深色外观下的配色主题 |
| `theme-light` | string | Kero 的浅色默认 | 浅色外观下的配色主题 |
| `font-family` | string | 内置 JetBrains Mono | 终端、编辑器和 diff 的字体 |
| `font-size` | number | `13` | 磅值，8–32 |
| `font-thicken` | bool | `false` | 更粗的字形笔画 |
| `editor.wrap-lines` | bool | `false` | 编辑器软折行 |
| `terminal.restore-history` | bool | `false` | 重启时恢复滚动缓冲区 |

```toml title="~/.config/kero/config.toml"
theme = "dark"
theme-dark = "Catppuccin Mocha"
font-family = "IBM Plex Mono"
font-size = 14
terminal.restore-history = true
```

主题名写错时会退回默认值，而不是让选择器空着——所以一个笔误不会把你锁在设置窗口外面。

<Callout type="warn">
Debug 构建读的是 `~/.config/kero-dev/config.toml`，所以它和已安装的 Kero 一起跑也不会覆盖
你真正的设置。
</Callout>

按 <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd>。信息面板描述的是**当前聚焦的会话**——
不是项目——并且随着东西启停实时刷新。

## 目录

分成两项，因为它们并不总是同一个：

- **Current Directory**——shell 实时的工作目录，和下面那个不同时才显示。
- **Project Directory**——文件和 git 面板锚定的文件夹，Kero 自动推导时标着 `(AUTO)`。旁边的 `?` 会解释这两种模式。

紧挨着它们的是几个快捷操作：在 **Finder** 中显示、用 **VS Code** 打开（装了才有）、以及 **Copy** 路径。

## 进程

会话 shell 底下跑着的所有东西，带 PID、CPU 百分比和常驻内存。右键某个进程可以：

- **Terminate**——客气的 `SIGTERM`
- **Force Kill**——`SIGKILL`，对付不听劝的
- **Copy PID** / **Copy Executable Path**

已经退出、还在等待回收的子进程（`<defunct>`）不会列出来——那里既没有输出可看，也没有东西可杀。

## 端口

这些进程正在监听的 TCP 端口，以及各自属于哪个进程。用来回答那些日常问题：*这次开发服务器又挑了哪个端口*，还有*到底是什么还占着 3000*。

- 点端口在浏览器里打开 `http://localhost:<port>/`
- **Copy URL**
- **Kill Process**——当「什么还占着它」的答案是「某个我忘了的东西」时

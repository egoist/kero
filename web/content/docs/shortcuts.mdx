---
title: Keyboard shortcuts
description: Every default shortcut in Kero, grouped by what it does.
---

Forgot one? <kbd>Cmd</kbd>+<kbd>P</kbd> opens the command palette and lists each
command's shortcut beside it.

## Projects and sessions

| Shortcut | Action |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>N</kbd> | New project |
| <kbd>Cmd</kbd>+<kbd>T</kbd> | New session |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> | New window |
| <kbd>Cmd</kbd>+<kbd>W</kbd> | Close the focused pane |
| <kbd>Cmd</kbd>+<kbd>1</kbd>–<kbd>9</kbd> | Switch to project 1–9 |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>]</kbd> / <kbd>[</kbd> | Next / previous project |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>1</kbd>–<kbd>9</kbd> | Switch to tab 1–9 |
| <kbd>Ctrl</kbd>+<kbd>Tab</kbd> | Tab switcher, ordered by recent use |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>]</kbd> / <kbd>[</kbd> | Next / previous tab |

## Panes

| Shortcut | Action |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>D</kbd> | Split right |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | Split down |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+arrows | Focus the pane in that direction |
| <kbd>Cmd</kbd>+<kbd>[</kbd> / <kbd>Cmd</kbd>+<kbd>]</kbd> | Cycle pane focus |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Return</kbd> | Toggle pane zoom |
| <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+arrows | Resize the focused pane |
| <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+<kbd>=</kbd> | Equalize panes |

Split left and split up have no default shortcut — use the **Tabs** menu, the
pane's context menu, or the command palette.

| --- | --- |

<Callout title="Why not ⌘ ⇧ ⌥ ⌃?">
The symbols are spelled out here because the site's monospace font has no glyphs
for them — they'd fall back to a different family mid-word, and vanish entirely
on most non-Apple systems. Inside the app you'll see the real symbols.
</Callout>

## Find previous

<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> is the usual macOS shortcut for
Find Previous, but in Kero it toggles the git panel. Use
<kbd>Shift</kbd>+<kbd>Return</kbd> in the find bar instead — the menu item under
**Edit → Find** works too.

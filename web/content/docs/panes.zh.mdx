---
title: 分屏与窗格
description: 把标签页切成多个窗格，在它们之间移动、调整大小，或把一个放大到全屏。
---

任何标签页都能分屏。窗格里通常是终端，也可以是文件、diff 或[浏览器](/zh/docs/browser)——
这正是重点：正在读的东西就摆在产生它的那个 shell 旁边。

## 分屏

| 操作 | 快捷键 |
| --- | --- |
| 向右分屏 | <kbd>Cmd</kbd>+<kbd>D</kbd> |
| 向下分屏 | <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> |
| 向左分屏 | — |
| 向上分屏 | — |

向左和向上分屏没有默认快捷键；从 **Tabs** 菜单、命令面板（<kbd>Cmd</kbd>+<kbd>P</kbd>）或窗格自己的右键菜单里执行。新窗格会继承当前窗格的工作目录。

分屏永远只切开**当前聚焦的窗格**，嵌套布局里也一样，不会改变无关邻居的尺寸。每个窗格头部都有一条小标题和本地分屏控件，终端实时标题也会显示在那里。

已经打开的窗格也可以重排：抓住窗格顶部那条细条，拖到另一个窗格的边缘。松手之前，目标窗格会先显示它将落在哪一半。

整个标签页也能变成窗格。把顶部标签拖到当前标签页内容的左、右、上或下边缘，松手前会先看到最终分屏的预览。

## 在窗格之间移动

| 操作 | 快捷键 |
| --- | --- |
| 聚焦左 / 右 / 上 / 下方的窗格 | <kbd>Opt</kbd>+<kbd>Cmd</kbd>+方向键 |
| 向前 / 向后循环切换焦点 | <kbd>Cmd</kbd>+<kbd>[</kbd> / <kbd>Cmd</kbd>+<kbd>]</kbd> |

## 放大与调整大小

<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Return</kbd> 把当前窗格放大到铺满标签页，再按一次还原。有窗格处于放大状态时，标签页头部会出现一个按钮，所以你总有一条不靠快捷键的退路。

| 操作 | 快捷键 |
| --- | --- |
| 切换窗格放大 | <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Return</kbd> |
| 朝某个方向放大窗格 | <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+方向键 |
| 让所有窗格等分 | <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+<kbd>=</kbd> |

窗格之间的分隔条也可以直接拖。

## 关闭

<kbd>Cmd</kbd>+<kbd>W</kbd> 关闭当前窗格。关掉标签页里最后一个窗格，标签页也一起关掉。

<Callout type="warn">
关闭一个终端窗格会终止里面的 shell，以及它启动的所有东西。Kero 不会先问一句——这和在别处关掉一个终端是一回事。
</Callout>
